# Doodle Pop

A simple drawing board for kids on tablets. It has a pencil, a brush, a rainbow brush, a paint bucket, stamps, an eraser, undo, coloring pages, and a one-tap button to save the picture as a PNG.

**Tech:** TanStack Start, React 19, Tailwind CSS 4, and HTML canvas. It runs entirely in the browser and is deployed on Netlify.

## Run locally

```bash
pnpm install
pnpm dev        # http://localhost:3000
```
